# Driver-For-Microsoft-LifeCam-VX-1000

For installing the driver you just unzip the file and run the .bat script and it's done !

If it doesn't work correctly :

Unzip the file ; 
go into the device manager ; 
select the device (normally called "LifeCam VX-1000", or "Camera") ; 
click on the "update driver" ; 
select "browse my computer to search for drivers" ; 
click on "browse..." ; 
select the folder "LifeCam_1_4 VX-1000\LifeCam1_4" ; 
click on "next" ; 

normlly, the driver is installed correctly !
